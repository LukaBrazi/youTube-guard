# kids-youtube-curator

Скіл для Claude, який щоранку прибирає рекомендації YouTube у дитячому профілі. Він блокує сміттєві канали (скібіді, Elsagate, ШІ-генероване), береже білий список, додає науково-популярні ролики й мультики у «Переглянути пізніше», навчає алгоритм переглядом і лайком і надсилає звіт.

Перед будь-якою дією скіл перевіряє, що активний профіль справді дитячий. Якщо ні – не робить нічого і повідомляє, що запуск пропущено.

## Швидкий старт

1. Постав Claude in Chrome і зайди в дитячий профіль YouTube у Google Chrome.
2. Встанови скіл (див. «Встановлення»).
3. Один раз запусти вручну: «почисти ютуб дитині» – і дай відповіді на питання.
4. Створи заплановане завдання на щоранку.

## Що потрібно

- Платний план Claude.
- Google Chrome з розширенням Claude in Chrome з Chrome Web Store. Підходить тільки Google Chrome, інші браузери на Chromium не підтримуються.
- Дитячий профіль YouTube, у який виконано вхід у цьому Chrome.
- Комп'ютер, який не спить у час запуску. Завдання, якому потрібен твій комп'ютер, не виконується, поки комп спить.

Я запускаю на Opus 5.

## Встановлення

Репозиторій називається `youTube-guard`, а скіл – `kids-youtube-curator`. Тека зі скілом у тебе має називатись саме `kids-youtube-curator`, тож назву при встановленні вказуємо явно.

**Claude Code.** Одна команда – склонувати репозиторій одразу в теку скіла:

```bash
git clone https://github.com/LukaBrazi/youTube-guard ~/.claude/skills/kids-youtube-curator
```

Так скіл буде доступний у всіх проєктах. Якщо треба тільки в одному проєкті – клонуй у `.claude/skills/kids-youtube-curator` всередині цього проєкту.

Оновитись до свіжої версії: `git -C ~/.claude/skills/kids-youtube-curator pull`.

**claude.ai.**

1. На сторінці репозиторію натисни Code – Download ZIP і розпакуй архів.
2. Перейменуй розпаковану теку `youTube-guard-main` на `kids-youtube-curator`.
3. Запакуй цю теку назад у zip.
4. Завантаж zip через Settings – Features. Потрібен платний план.

## Перший запуск

Запусти скіл вручну, наприклад: «почисти ютуб дитині». Скіл запитає:

- назву дитячого профілю YouTube – точно так, як вона показана в меню аватара;
- вік дитини та інтереси;
- якими мовами контент можна додавати, а якими – ні;
- додаткові стоп-слова;
- канали для білого списку;
- мультики і скільки роликів додавати на день.

Порожня відповідь означає значення за замовчуванням. У Claude Code скіл запише налаштування в `SKILL.md`, якщо ти погодишся. У claude.ai він видасть готовий блок – встав його в розділ «Налаштування» у `SKILL.md` і завантаж zip ще раз.

Поки налаштування не заповнені, запуск за розкладом нічого не робить і просить запустити скіл вручну.

## Щоденний запуск

Створи заплановане завдання з текстом на кшталт «Запусти скіл kids-youtube-curator». Заплановані завдання є на всіх платних планах, розклад – щогодини, щодня, щотижня, у будні або вручну. Для дитячого профілю вистачить раз на день, зранку.

## Що скіл робить

1. Перевіряє, що активний профіль – той, що в налаштуваннях. Не збіглося – зупиняється.
2. Дивиться історію за останню добу.
3. Проходить по рекомендаціях і через «Не рекомендувати канал» блокує канали зі стоп-словами, із забороненою мовою та очевидне сміття.
4. Додає у «Переглянути пізніше» нові ролики з білого списку під вік та інтереси.
5. За бажанням додає серії мультиків.
6. Програє 1–2 хороші ролики по 30–60 секунд і ставить лайк.
7. Надсилає звіт: що заблоковано, що спірне, що додано, що не вдалося.

## Гарантії

- **Не той профіль – нуль дій.** Ні лайків, ні блокувань, ні роликів. Тільки звіт про пропущений запуск. Профіль перевіряється ще раз перед кожним блоком дій.
- **Білий список сильніший за стоп-слова.** Канал із довірених не блокується, навіть якщо в назві ролика стоїть «челендж».
- **Сумнів – не блокувати.** Усе неочевидне потрапляє у звіт як спірне.
- **Повторний запуск не дублює.** Вже додані ролики не додаються вдруге, вже поставлений лайк не знімається.
- **Не знайшов кнопку – пише у звіт.** Жодних обхідних шляхів.

## Чого скіл ніколи не робить

Не змінює налаштування акаунта, не видаляє історію, не підписується й не відписується, не змінює вікові обмеження, не перемикає профілі, не скаржиться на ролики, не коментує і нічого не купує.
