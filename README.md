# youTube-guard
Щоденне прибирання рекомендацій YouTube у дитячому профілі: блокує сміття, береже білий список, додає корисне, навчає алгоритм, звітує. Спершу перевіряє, що профіль справді дитячий. Використовуй, коли просять почистити ютуб дитині, навести лад у дитячих рекомендаціях чи прибрати скібіді й Elsagate зі стрічки.
